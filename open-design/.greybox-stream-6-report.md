## Known concerns

1. **/v1/billing/me does not exist on greybox-cloud yet.** The daemon proxy treats 404 as the "free" baseline so the /billing UI keeps working. Surface this with the cloud team so subscription state is wired before Day-90 GA.
2. **Playwright e2e specs are authored but not executed in this stream.** They live under `apps/web/e2e/` (the task-spec location) but the existing playwright runner is at `open-design/e2e/playwright.config.ts` and scoped to `e2e/ui/`. To wire them up, either point `testDir` at `apps/web/e2e/` or copy them under `e2e/ui/billing.spec.ts` etc. before CI. Browser binaries are not installed in this workspace so they were not invoked.
3. **The /billing UI surfaces $19 / $49 prices that do not match the cloud's PLAN_METERING table ($29 / $79).** The task spec explicitly asked for $19 / $49 display copy. Reconcile before launch by either updating cloud PLAN_METERING or moving display copy to a value passed by /v1/billing/plans.
4. **The ThemeToggle is exported but not yet mounted in the user menu / settings.** Stream 6 added the toggle component but did not edit `AvatarMenu.tsx` / `SettingsDialog.tsx` because those are large surfaces touched by other streams. Mount it with `<ThemeToggle />` inside the appropriate menu when the user-menu team picks Stream 6 up.
5. **Stream 1's design/lib/export.ts and design/lib/persistence.ts still violate `pnpm guard`** — first-party project endpoints should use `/api/game-deliverables`. Out of Stream 6's scope; flag for Stream 1.
6. **Pre-existing test failures upstream:**
   - `apps/daemon/tests/game-playtest-simulation-routes.test.ts` — 120s timeout (headless-browser dependent)
   - `apps/daemon/tests/project-watchers.test.ts` — chokidar timing flake

   - `apps/web/tests/components/GameTelemetryBoard.test.tsx` — pre-existing `window.localStorage.clear is not a function` (Stream 6 worked around the same issue in its own tests by stubbing `localStorage` via `vi.stubGlobal`)
