# Production Feasibility

Production feasibility protects the core fantasy by cutting the wrong complexity early.

## What To Produce

- Team scale, timeline, milestone plan, discipline dependencies, content budget, and major risks.
- Solo, indie, AA, and AAA versions when the idea is large or ambiguous.
- A vertical-slice cutline that proves the core loop with the fewest systems.

## Design Rules

- Preserve the fantasy before preserving the mechanic list.
- Identify the highest-risk system first: networking, AI, animation, content volume, economy, tools, or rendering.
- Convert vague scope into countable units: enemies, weapons, levels, quests, biomes, cinematics, VFX, HUD/menu screens.
- Use placeholders intentionally and name what they validate.
- Prefer reusable systems over one-off content when team size is small.

## Production Gates

- Include build order, staffing assumptions, QA risks, localization needs, and platform certification risks.
- Name dependencies that can block other teams.
- Include a fallback if the hardest system fails.

## Agent Checklist

- Include feasible scope tiers.
- Include milestone and vertical-slice plan.
- Include asset and engineering budgets.
- Include risks and cuts that keep the game shippable.
