# Open World Systems

Open worlds work when exploration, traversal, density, and systemic surprise reinforce the player fantasy.

## What To Produce

- Region structure, biome transitions, traversal routes, faction territories, discovery types, and dynamic events.
- Content-density rules for critical path, optional paths, secrets, resources, and rest spaces.
- A world-state model for persistence, respawns, faction influence, and event escalation.

## Design Rules

- Every region needs a readable promise: danger, reward, story, traversal, or mastery.
- Travel time should create anticipation, not filler.
- Discovery rewards should vary between power, story, economy, social, cosmetic, and shortcut value.
- Dynamic events must be legible from a distance and resolve into meaningful world-state consequences.
- Prevent open-world fatigue with contrast: safe hubs, high-risk zones, quiet vistas, and focused objectives.

## Production Gates

- Estimate terrain, prop, encounter, quest, AI, and streaming budgets by region.
- For indie scope, design fewer regions with deeper systemic reuse.
- Track telemetry: route heatmaps, skipped regions, time between discoveries, event completion, and resource saturation.

## Agent Checklist

- Include world layout and density rules.
- Include traversal and reward cadence.
- Include faction or simulation logic.
- Include a scoped vertical-slice region.
