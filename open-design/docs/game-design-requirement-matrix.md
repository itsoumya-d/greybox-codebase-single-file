# Game Design Requirement Matrix

**Parent:** [`game-design-transformation-audit.md`](game-design-transformation-audit.md)
**Completion audit:** [`game-design-completion-audit.md`](game-design-completion-audit.md)

This matrix turns the transformation prompt into an item-by-item evidence checklist. It is not a completion certificate. `Covered` means there is concrete code, content, or test evidence in the current repository. `Partial` means the repository has prompt, schema, skill, UI, ingestion, scheduling, or planning support but does not yet prove every final-state claim end to end. Legacy compatibility surfaces are governed separately by [`game-design-compatibility-manifest.md`](game-design-compatibility-manifest.md).
