This localized README has been reset for the AI-native game design platform transformation.

AI Game Design Studio is no longer a generic interface generator. It is an AI game design studio for playable concepts, game systems frameworks, HUDs, level flow, narrative arcs, economy and progression, multiplayer planning, art direction, audio direction, live-ops strategy, and engine-aware production planning.

Use the primary [README.md](./README.md) as the source of truth while localized docs are rebuilt around the game-studio workflow.

Core workflow:

1. Analyze genre, platform, camera, audience, and emotional target.
2. Define gameplay pillars, core loop, player journey, and retention strategy.
3. Generate mechanics, levels, encounters, narrative, economy, HUD, art direction, audio, live ops, accessibility, and technical constraints.
4. Export production-ready GDDs, level boards, combat specs, balance sheets, art bibles, HUD wireframes, trailer prompts, and milestone plans.
