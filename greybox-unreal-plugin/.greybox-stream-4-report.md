## Component kinds implemented

UMG (widget graph):
- Button (onClick label + event id surfaced for FlowDispatcher routing)
- Image (asset ref → Texture2D path)
- Text (content, font, size, hex colour → sRGB linear)
- TextInput (placeholder, input type, max length)
- ProgressBar (min, max, value)
- HUDBar (stat key, bar style)
- MenuList (items dispatch via FlowDispatcher event ids)
- Container (layout, gap)

Level (actor graph):
- Character3DRef → ASkeletalMeshActor with skeletal-mesh + animation
  blueprint path
- GameObject → AStaticMeshActor with prefab path
- Camera → ACameraActor (projection, FOV, isMain)
- Light → ADirectionalLight | APointLight | ASpotLight | ARectLight
  (color, intensity, casts shadows)
- Spawner / Trigger / Pickup / Hazard / Checkpoint → AStaticMeshActor
  with the engine cube placeholder + GreyboxComponent metadata tag and
  every kind-specific scalar surfaced on the descriptor
- Particle → AEmitter (effect ref, autoPlay, loop)
- AudioSource → AAmbientSound (clip ref, volume, spatial, autoPlay)

Character pipeline:
- `<characterId>_SK` SkeletalMesh
- `<characterId>_Skeleton` Skeleton
- `<characterId>_PhysAsset` PhysicsAsset
- `<characterId>_ABP` AnimBlueprint
- `<characterId>_AnimClip_<n>` AnimSequence per `animations[]` entry
- Mixamo non-standard joints flagged via warnings (`IsMixamoStandardJoint`)

Asset pipeline:
- gltf / fbx → Skeletal/StaticMesh class hint
- png / jpg / webp → Texture2D
- mp3 / wav → SoundWave
- prefab → Blueprint
- json → DataAsset
- Unknown types still emit a descriptor + warning (never silently dropped)

Flow:
- A single `AGreyboxFlowDispatcher` actor descriptor with
  `componentIdToScreenId` + `eventIdToScreenId` maps. Widget blueprints
  reference the dispatcher from their `OnClicked` handler.

## Component kinds deferred

- Full Blueprint K2 event-graph synthesis per click (we emit the
  dispatcher + maps instead — same observable behaviour, far smaller and
  more testable surface). Documented in `GreyboxFlowImporter.h`.
- Animation blueprint state graph editing (we emit the ABP path and the
  per-clip AnimSequences but do not wire `OnTransition` rules). The
  default ABP is built by UE's importer with a single state.
- Live importer integration with `UInterchangeManager` (UE 5.4+ async
  pipeline) — we emit the descriptors and `UAssetImportTask`-ready paths;
  the actual UE-side glTF read is delegated to the commandlet runtime
  (and is unreachable from the CI box without an installed editor).

## DiffApplier status (which field types work)

All of:

- Int, Float, String, Bool — scalar 3-way rule.
- Hex Color — handled as a 7/9-character string; tuple-wise via the
  generic merge.
- FVector (x/y/z) — component-wise merge; conflict only on the changed
  axis.
- FRotator (pitch/yaw/roll) — component-wise; same as Vector.
- FTransform (position/rotation/scale objects) — recursive into each
  sub-object.
- Arrays:
  - Items with `id` / `componentId` / `screenId` / `characterId` /
    `assetId` / `edgeId` use id-stable reconciliation.
  - Additions, deletions, modifications all flagged.
  - Local-deletion-vs-remote-modification raises a conflict (and vice
    versa).
- Nested objects — recursive merge with JSON-Pointer paths.

Conflicts are returned with `JsonPointer`, `BaseValueJson`,
`LocalValueJson`, `RemoteValueJson`, `FieldType`, and a `Resolution`
field. `Resolve(result, pointer, choice)` mutates the merged JSON in
place and clears the `bHasConflicts` flag when no `Pending` resolutions
remain.
