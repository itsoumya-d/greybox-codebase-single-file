# Greybox Third Person Arena Sample

Sample placeholder for the Unreal alpha validation path.

Expected artifacts:

- `arena.gameview.json` for actor layout and combat encounter markers.
- `DESIGN.md` for palette, lighting, and material guidance.
- `arena-hud.html` for UMG conversion.
- `arena.levelboard.json` for lane, spawn, and objective layout.

The sample remains lightweight until Unity v1.0 proves the engine loop, then it
becomes the first Unreal Marketplace smoke scene.
