# Mobile Idle Sample

AI-assisted sample set. Human designer credit: Noor Designer.

Import the four Greybox artifact files in this folder into a portrait mobile
Unity project:

- `mobile-idle.gameview` builds stations, generators, rewards, and upgrade nodes.
- `mobile-idle.design` imports the soft-production palette as a ScriptableObject.
- `mobile-idle.gbhud` imports the portrait economy HUD.
- `mobile-idle.levelboard` builds the economy-loop board and tilemap beats for tuning.

The sample is tuned for live-ops pacing: adjust generator output, reward claims,
or upgrade placement and confirm the Greybox artifact can round-trip those edits.
