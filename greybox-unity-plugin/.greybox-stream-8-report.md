### C. `.unitypackage` build pipeline

- `scripts/build-unitypackage.sh` — bash wrapper. Reads `UNITY_PATH`,
  `UNITY_VERSION`, `GREYBOX_OUTPUT`, etc., delegates to
  `Validation~/unity-package-export.mjs`, then prints the byte count
  and sha256.
- `scripts/build-unitypackage.mjs` — cross-platform Node wrapper that
  imports the existing exporter helpers and adds Unity Hub auto-discovery
  + a `--dry-run` mode for CI lanes without a license. Dry-run output
  prints the full command including the required environment variable.
- Both scripts:
  - Pin the headless entrypoint to
    `Greybox.Editor.Export.GreyboxAssetStorePackageExporter.ExportFromCommandLine`.
  - Pass `-greyboxAssetStorePackageOutput` and set
    `GREYBOX_ASSET_STORE_PACKAGE_OUTPUT` to satisfy the existing exporter
    contract.
  - Verify the output file exists and is non-empty, then emit
    `bytes` + `sha256`.
  - Exit non-zero on any failure.
- `BUILDING.md` documents the full local flow including prerequisites,
  `UNITY_PATH`, screenshot capture checklist, troubleshooting, and the
  CI/release split.

   currently falls back to flat-colour PNGs (no watermark text) when
   Pillow is missing. Action: `python3 -m pip install --user Pillow`
   on the release machine before regenerating placeholders.
