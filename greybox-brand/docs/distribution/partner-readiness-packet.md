## Education Pilot Kit

- Free education terms for accredited programs.
- 90-minute lesson: block out a boss arena with Greybox, export to Unity, critique pacing.
- Assignment rubric: design pillars, readability, iteration loop, engine handoff.
- Instructor setup guide for BYOK mode and managed-inference opt-in.
- No model training on student work without a separate explicit opt-in checkbox.

## Partner Demo Spine

1. Designer creates a 2D platformer encounter in Greybox.
2. Unity refreshes the artifact within the round-trip sync window.
3. A coding agent uses the MCP bridge to change one gameplay field.
4. Greybox captures the engine screenshot and playtest report.
5. The human designer accepts or rejects the AI-assisted tuning diff.
