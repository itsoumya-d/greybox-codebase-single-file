# Greybox Naming Memo

Decision date: 2026-05-18

Chosen name: Greybox

Status: provisionally selected, pending trademark counsel, domain purchase, and
GitHub organization creation.

## Decision

Greybox is the primary brand for the AI-assisted design layer for shipped games.
It is the strongest fit because it is native to game-production language,
signals early playable space, and keeps the product focused on designers,
loops, pacing, feel, readability, and engine handoff.

Fallback order if counsel rejects Greybox in the relevant classes:

1. Pillar
2. Preplay
3. Loopforge
4. Mechanic

Do not mix names in product, plugin, docs, listing copy, or legal templates.
Until counsel signs off, public launch copy should say "Greybox" consistently
while keeping formal filing and registration status internal.

## Trademark Search Scope

This memo is not legal advice and does not claim clearance. Counsel must run
full knockout and comprehensive searches before filing.

Official search surfaces:

- United States: USPTO Trademark Search, https://www.uspto.gov/trademarks/search
- European Union: EUIPO Search IP, https://www.euipo.europa.eu/en/search-ip
- India: Intellectual Property India Trade Marks, https://www.ipindia.gov.in/Trademarks/trademarks

External refresh on 2026-05-21:

- USPTO's official search page links to the Trademark Search system and states
  it was last updated on 2026-04-08. The live search UI requires JavaScript and
  should be run by counsel or the founder from a signed-in USPTO session.
- EUIPO Search IP exposes eSearch plus and TMview as the relevant official EU
  search surfaces for trade marks.
- IP India publishes a Search Existing Trademarks path and public search portal.
- No clearance conclusion is recorded here; this memo only confirms the official
  search surfaces to use and keeps the filing blocker open.

Relevant filing classes to review:

- Nice Class 9: downloadable software, editor plugins, SDKs, and game tooling.
- Nice Class 42: SaaS, managed inference, cloud sync, and software design services.
- Nice Class 41: training, educational programs, workshops, and creator courses.

## Domain Search Scope

Required TLDs for the selected name and every fallback:

- `.studio`
- `.gg`
- `.ai`
- `.com`

DNS spot check on 2026-05-18 showed existing A or AAAA records for
`greybox.studio`, `greybox.ai`, and `greybox.com`. `greybox.gg` did not return
an A or AAAA record in the local DNS check. DNS is not proof of registration
availability; registrar or registry checks are still required.

External refresh on 2026-05-21:

- ICANN describes its Whois Search as the source for registered-domain lookup
  details, but final acquisition still requires registrar checkout access.
- Public search results continue to show `greybox.com` as registered; treat
  aggregator results as non-authoritative until confirmed in ICANN Lookup and
  the registrar purchase flow.
- Search did not produce an authoritative `@greybox-studio` GitHub organization
  ownership record; organization creation remains blocked on founder credentials.

- Founder or counsel must file US, EU, and India trademark applications.
