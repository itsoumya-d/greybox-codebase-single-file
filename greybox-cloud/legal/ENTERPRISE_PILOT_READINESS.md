# Greybox Enterprise Pilot Readiness

This packet is internal go/no-go evidence for the first five Studio or
Enterprise pilots. It is not legal advice, a signed customer agreement,
auditor assurance, SOC 2 or ISO 27001 certification, or proof of production
deployment.

Use `GET /v1/enterprise/pilot-readiness` with an admin bearer token before
committing to a $40K+ annual contract, private-network pilot, on-prem install,
or data-residency commitment.

The report combines:

- Order Form/MSA/DPA procurement packet readiness from `/v1/enterprise/contracts`.
- Security questionnaire blockers from `/v1/enterprise/security-questionnaire`.
- SSO, SCIM, audit export, privacy, AI minimization, residency, on-prem, and
  private-network trust evidence.
- SOC 2 / ISO 27001 roadmap status from `/v1/enterprise/certification-roadmap`.

The report fails closed when required procurement or security evidence is
blocked. Warnings are allowed for pilots only when the customer-facing claim is
scoped in the order form and the owner has a remediation plan.

Enterprise sales targets:

- First logo target: 5 enterprise pilots.
- Minimum ACV: $40,000.
- Target average ACV: $60,000.
- Regions tracked: US, EU, India.
