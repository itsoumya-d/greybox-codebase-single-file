## 0. Executive Summary

Greybox Studio is **an AI-native game-design studio that lives next to Unity, not inside it**. The thesis: designers and indie devs work in a web/desktop studio to produce concept-to-content artifacts (game design docs, art bibles, prefab graphs, HUDs, palettes, scene-board JSON, prompts, key art, trailer beats), and a paid plugin layer **drops those artifacts directly into a Unity project as real assets** (prefab graphs, palette `.asset`, addressables labels, MCP-driven scene mutations).

It is **not** an engine, not a Unity replacement, not a code generator. It is the **content/design pipeline** between AI generation and the engine — the closest analog is "Figma → Webflow → React" but for "AI design studio → Unity → game."

## 2. Architecture Review

**Strengths:**

1. **Clean separation by trust boundary.** Open-source studio (no IP defensibility, max distribution) ↔ proprietary cloud (revenue) ↔ proprietary plugin (moat) ↔ proprietary content bundles (NRR). Each repo has a clear ownership story for a buyer.
2. **Sidecar IPC abstraction.** `open-design/packages/sidecar-proto` cleanly isolates daemon ↔ desktop ↔ web. Desktop discovers daemon over IPC, not OAuth — good for "your code stays local" pitch.
3. **MCP-first Unity plugin.** 1,086-LOC JSON-RPC 2.0 server with 8 production tools, bearer-token auth, round-trip integration tested. **This is the architectural bet that pays off now that Unity AI ships native MCP support in 2026** — Greybox becomes a first-class extension surface, not a competing tool.
4. **Honest crypto.** AES-256-GCM authenticated encryption + Ed25519 signing in `greybox-pro/src/bundles/gbpro.ts` with `keyId` for rotation. The primitives are right.
5. **Real `.unitypackage` builder.** 644-LOC tar+gzip with correct GUID assignment + `.meta` files. Not a toy.
6. **Hash-chain audit log in cloud.** `greybox-cloud/src/enterprise/auditLog.ts` 22 action types. Enterprise-credible foundation.
7. **PII discipline in playtest.** SHA-256 hashing + regex redaction for email/phone in `greybox-playtest/src/reporter/userStudy.ts`. GDPR-ready posture.

**Weaknesses:**

1. **File-based state where Postgres is needed.** Cloud's TenantStore is an in-memory Map; SCIM is JSONL; marketplace persistence is whole-file snapshot. Breaks past ~10K creators or any concurrent control-plane writers. **Platform fix:** Postgres + Prisma/Drizzle. 2.5 weeks cloud, 1 week marketplace.
2. **MCP handler asymmetry.** Unity has 8 declared, 8 handled, integration-tested. Unreal: 8 declared, **0 handler dispatch logic in `GreyboxMcpBridge.cpp`** (58 LOC total). Godot: same. **This is bigger than internal docs imply** — Unreal is not 4-6 weeks behind, it's "MCP dispatch not started." Realistic estimate: 10-12 weeks for Unreal, 12-14 for Godot to reach parity.
3. **No multi-version CI matrix on plugins.** No GitHub Actions covering Unity 2022.3 / 2023.2 / Unity 6 (or Unreal 5.3/5.4/5.5, Godot 4.2/4.3/4.4). For a paid Asset Store SKU this is table stakes. 0.5w Unity, 1w Unreal.
4. **Frontend polish gap.** open-design web app has **53 @media queries across 55+ components** — coverage is shallow (~3% by component count). The CSS uses `color-scheme: dark` site-wide with no light-mode fallback or toggle. For an "AI-native design tool" sold to designers, the UX surface is a credibility liability.
5. **License validation fallback.** Cloud `licenses.ts:61-75` accepts prefix matching (`gbx_indie_`, `gbx_pro_`) when no signed record is found and `allowPrefixFallback !== true`. Bypassable in misconfigured prod; needs the Ed25519 path forced on for paid tiers.
6. **No CDN for Pro bundles.** Bundles are static JSON envelopes. Customer download path = "filesystem" today. Cloudflare R2 or similar is a week of work.
7. **server.ts at 12,141 lines.** Organized but a single-file daemon at that size is a recruiting/onboarding tax and a refactor liability for any acquirer.

**Verdict:** Architecture is **fundamentally sound** — clean trust boundaries, proper crypto, MCP-first plugin design. The weaknesses are operational debt (state, CI, CDN, file split) not architectural reboots.

## 4. Scalability Analysis

**Bottlenecks that bite first:**

| Bottleneck | Today's ceiling | Required fix | Effort |
|---|---|---|---|
| Cloud TenantStore (in-memory Map) | ~hundreds of tenants, single replica | Postgres + connection pool | 2.5w |
| Cloud SCIM JSONL | ~10K SCIM rows before append latency hurts | Postgres + index | 1w (rolls into above) |
| Marketplace snapshot persistence | ~10K creators / $25K GMV before write contention | Postgres + audit log table | 1.5w |
| `unity-package-builder.ts` (in-memory tar build) | ~50MB packages (single Node heap) | Stream to disk; chunk | 1w |
| Pro bundle distribution | ~hundreds of downloads/day from one daemon | Cloudflare R2 + signed URLs | 1w |
| Daemon `server.ts` 12K LOC monolith | Survivable for years; hostile for acquirer DD | Split routes into modules | 4w (cosmetic, not blocking) |
| Inference proxy (cloud) | Anthropic/OpenAI rate limits; need multi-key pooling + queue | Token-bucket + retry + Redis queue | 2w |
| Plugin Asset Store distribution | N/A — Unity Asset Store handles fan-out | None | — |

**Horizontal scaling story:** Once cloud is Postgres-backed and inference proxy has a Redis queue, the platform scales to "low-thousands of paying seats" on a 2-node Render/Fly setup. The plugin scales to whatever Unity Asset Store throws at it (no infra cost). The marketplace is the only thing with O(N²) growth pressure (every creator × every buyer × every refund), and it doesn't need to scale until you're past 1K creators.

**Bandwidth/cost model (BYOK assumed for indie/studio tiers):** $0 inference cost on free + BYOK tiers. ~70% gross margin on managed-inference enterprise SKU. Bundle CDN cost: <$50/mo until >1K paying Pro customers.

## 6. Best Deployment Model

**Recommendation: Hybrid web-primary, with three coordinated surfaces.**

| Surface | Role | Build now? | Why |

| **Web SaaS** (Next.js + managed daemon on Render/Fly/Vercel) | Front door — distribution, free tier, collaboration, analytics, multiples | **Yes (primary)** | SaaS multiples (4-12x ARR) are 3-5x what desktop tools get. Top-of-funnel happens on the web. |

- Mobile native app (no buyer; no workflow fit)

- Apache-2.0 + desktop = no recurring revenue lever, no NRR, no SaaS multiples. You'd top out at ~$2M-$5M ARR and 3-4x exit.

**Why not pure web:**
- Enterprise IP-protection objection kills 50% of large deals. The Electron shell is your trust card. Keep it.

**Why not desktop + plugin only (no web):**
- You lose the marketing funnel, the free tier, the ungated viral surface, the marketplace, and the collaboration story — which is the only path to $20M+ ARR.

**Position vs Unity AI specifically:** "Unity AI is for Unity engineers. Greybox is for game designers. Greybox feeds Unity AI — and the rest of your pipeline."
