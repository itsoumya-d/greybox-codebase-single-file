## DiffApplier

Type coverage:
- Scalars: int, float, String, bool — full equality with int/float coercion fallback.
- Vectors: Vector2, Vector3 — `is_equal_approx` comparison.
- Quaternion — `is_equal_approx` comparison.
- Color — `is_equal_approx` comparison.
- Dictionary — recursive merge with deletion detection.
- Array — merges by `id` field when every element carries one; otherwise positional merge with element-by-element conflict reporting.

Conflict object shape: `{ path, base_value, local_value, remote_value, resolution }`. `resolve_conflict(merged, conflict, RESOLUTION_*)` mutates the merged tree along the path.
